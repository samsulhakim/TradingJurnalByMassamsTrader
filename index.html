Otomatisasi & Koneksi MT5 (MetaTrader 5)

Aplikasi jurnal web ini mendukung 2 metode integrasi MT5 agar data transaksi Anda masuk secara cepat & otomatis:

1 Otomatis Real-time dengan Expert Advisor (EA MQL5)

Setiap kali Anda men-close posisi/trade di MT5, EA ini akan otomatis mengirimkan data transaksi ke Google Sheet / Aplikasi Jurnal Anda.

  1. Buka MetaTrader 5 -> Tekan F4 (MetaEditor).
  2. Buat File Baru -> Expert Advisor (template) -> beri nama TradeJournalSync.
  3. Di MT5: Buka Tools > Options > Expert Advisors -> Centang Allow WebRequest for listed URL, lalu masukkan URL Web App Google Script Anda.
  4. Salin kode MQL5 di bawah ini ke MetaEditor, masukkan URL Google Script Anda di baris `InpScriptURL`, lalu klik Compile:
//+------------------------------------------------------------------+
//|                                             TradeJournalSync.mq5 |
//+------------------------------------------------------------------+
#property copyright "TradeJournal Pro"
#property version   "1.00"

input string InpScriptURL = "URL_GOOGLE_APPS_SCRIPT_ANDA"; 

void OnTradeTransaction(const MqlTradeTransaction& trans,
                        const MqlTradeRequest& request,
                        const MqlTradeResult& result)
{
   if(trans.type == TRADE_TRANSACTION_DEAL_ADD)
   {
      ulong deal_ticket = trans.deal;
      if(HistoryDealSelect(deal_ticket))
      {
         long entry = HistoryDealGetInteger(deal_ticket, DEAL_ENTRY);
         if(entry == DEAL_ENTRY_OUT || entry == DEAL_ENTRY_INOUT)
         {
            string symbol = HistoryDealGetString(deal_ticket, DEAL_SYMBOL);
            long type = HistoryDealGetInteger(deal_ticket, DEAL_TYPE);
            double volume = HistoryDealGetDouble(deal_ticket, DEAL_VOLUME);
            double price = HistoryDealGetDouble(deal_ticket, DEAL_PRICE);
            double profit = HistoryDealGetDouble(deal_ticket, DEAL_PROFIT) + 
                            HistoryDealGetDouble(deal_ticket, DEAL_SWAP) + 
                            HistoryDealGetDouble(deal_ticket, DEAL_COMMISSION);
            datetime time = (datetime)HistoryDealGetInteger(deal_ticket, DEAL_TIME);
            
            // Format Payload JSON
            string json = StringFormat(
               "{\"action\":\"add\",\"id\":\"%i\",\"date\":\"%s\",\"pair\":\"%s\",\"type\":\"%s\",\"lot\":%.2f,\"entry\":0,\"exit\":%.5f,\"pnl\":%.2f,\"notes\":\"MT5 Deal #%i\"}",
               deal_ticket,
               TimeToString(time, TIME_DATE),
               symbol,
               (type == DEAL_TYPE_BUY ? "SELL" : "BUY"), 
               volume,
               price,
               profit,
               deal_ticket
            );

            char data[];
            char result_data[];
            string headers = "Content-Type: application/json\r\n";
            StringToCharArray(json, data, 0, WHOLE_ARRAY, CP_UTF8);
            ArrayResize(data, ArraySize(data)-1);
            
            string result_headers;
            int res = WebRequest("POST", InpScriptURL, headers, 3000, data, result_data, result_headers);
            if(res == 200) Print("Trade berhasil di-sync ke TradeJournal!");
         }
      }
   }
}
2 Metode 2: Impor Laporan File MT5 (HTML / CSV)

Sangat mudah tanpa perlu pasang EA di MT5:

  1. Buka MT5 Desktop -> tab History di panel bawah.
  2. Klik kanan pada area riwayat transaksi -> pilih Report > Open XML / HTML Report.
  3. Klik tombol "Impor Report MT5" di sebelah kolom pencarian jurnal ini, lalu upload file report tersebut. Semua trade akan masuk otomatis!
